# Настройка настоящей отправки SMS через SMS Aero

SMS-канал проекта использует HTTP API SMS Aero. Это настоящий внешний провайдер: для отправки нужен аккаунт, API-ключ и положительный баланс.

## 1. Получить API-ключ

1. Зарегистрируйтесь или войдите в SMS Aero.
2. Откройте настройки личного кабинета.
3. Найдите раздел `API и SMPP` или `API-ключ`.
4. Сгенерируйте обычный API-ключ.

Тестовый API-ключ подходит только для настройки интеграции без реальной доставки. Для проверки прихода SMS на телефон нужен обычный API-ключ.

## 2. Добавить переменные в `.env`

```env
SMS_LOGIN=ваш-email-в-smsaero
SMS_API_KEY=ваш-api-key
SMS_SENDER=SMSAero
SMS_TEST_MODE=false
```

`SMS_LOGIN` - это email аккаунта SMS Aero. Пароль от личного кабинета в проект не нужен.

## 3. Указать номер жителя

Номер хранится в поле `Phone` у жителя. Для проверки можно обновить первого жителя:

```powershell
docker compose -p smartuk exec -T postgres psql -U uk_user -d uk_management -c "UPDATE \"Residents\" SET \"Phone\" = '+79307935899' WHERE \"Id\" = 1;"
```

## 4. Перезапустить web

```powershell
docker compose -p smartuk up -d --build web
```

После этого на странице `Уведомления -> Новое уведомление` выберите канал `SMS` и отправьте сообщение конкретной квартире или всем жильцам.

## 5. Как читать результат

SMS Aero может сначала вернуть статус `moderation`. Это означает, что провайдер принял запрос и проверяет текст. После успешной отправки статус меняется на `delivery`.

Если сообщение отклонено, в личном кабинете SMS Aero будет указана причина. Для проверки лучше использовать нейтральный служебный текст, например: `Тестовое сообщение SmartUK`.
