# Пояснительная записка: структура

## Введение

Актуальность автоматизации деятельности управляющей компании ЖКХ, цель, задачи, объект и предмет исследования.

## 1 Аналитическая часть

Описание предметной области, основные процессы УК, анализ аналогов и проблем ручного сбора показаний.

## 2 Проектная часть

Требования, роли пользователей, архитектура, диаграммы компонентов и потоков данных.

## 3 Технологическая часть

Обоснование C# / ASP.NET Core, Python, PostgreSQL, MQTT, Keycloak, Docker Compose.

## 4 Реализация

Описание backend, веб-интерфейса диспетчера, кабинета администратора, личного кабинета жильца, симуляции LoRaWAN/IoT-приборов, MQTT-сбора, уведомлений, отчетов по потреблению ресурсов и структуры БД.

## 5 Тестирование

Модульные тесты, проверка MQTT-сценария, проверка email-доставки через Mail.ru, SMS-доставки через SMS Aero, сообщений в профиле жильца, Web Push, формирования Word-отчетов, анализ зависимостей, CI и CodeQL/SAST.

## Заключение

Итоги, ограничения, перспективы: мобильное приложение жителя, интеграция с настоящими LoRaWAN-шлюзами, расширенная аналитика.
